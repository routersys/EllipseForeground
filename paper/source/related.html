関連研究

前景抽出とグラフカット

Boykov と Jolly は、利用者が前景と背景の画素に印を付け、領域の情報と境界の情報を合わせたエネルギーを最小カットで大域的に最小化する方法を示した。バイナリ変数のエネルギーのうち、グラフカットで最小化できる条件は Kolmogorov と Zabih が与えている。Rother らの GrabCut は、利用者が矩形で囲んだ領域から色分布を推定し、最小カットと分布の推定を繰り返して前景を求める。Lempitsky らは、利用者の矩形が分割結果を十分に密に囲むという位相的な制約を、エネルギーの最小化に加える方法を示した。

これらは、矩形が前景の外接矩形に近いことを前提にする。本稿の楕円は、被写体の外接矩形に内接する楕円に対し、縦横の半径を0.8〜1.6倍に変え、中心を動かしたものである。前景が楕円からはみ出し、内側に背景が広く含まれるため、矩形の接触に基づく制約は使えない。では、画素単位のグラフカットを比較手法として使う。

階層的な領域分割と木の上の切断

単連結法による階層的クラスタリングの結果は、最小全域木から得られる。画像の隣接画素を辺とするグラフにこれを適用すると、辺の重みの小さい順に領域を併合する木が得られる。Felzenszwalb と Huttenlocher は、領域の内部の変化と領域間の境界の強さを比べる併合の基準を持つグラフベースの分割法を示した。Salembier と Garrido は、領域を併合した二分木（binary partition tree）を、画像処理や分割、情報検索のための表現として提案した。Guigues らは、適合度の項と正則化の項からなるエネルギーを最小にする分割を、尺度の階層（scale-sets）から求めた。Arbeláez らは、輪郭検出の結果から領域のデンドログラムを作る方法を示した。Hu らの Tree-Cut は、領域の木の上で切断の確率分布を定め、動的計画法で厳密に推論する。

本稿はこの系統に属する。違いは、目的関数に利用者の楕円に由来する事前分布と画像の手がかりを入れた点、および木の各節点の領域について境界辺の弱さの平均を厳密に求めて境界項に使う点にある。

アルファマットと正解の取得

アルファチャンネルによる画像の合成は Porter と Duff が定式化した。自然画像のマッティングでは、Levin らが前景と背景の色の局所的な滑らかさを仮定し、疎な線形方程式を解いてアルファを求める方法を示した。マッティング手法の評価には、正解の付いた画像と、知覚に基づく誤差尺度を備えた評価基盤が使われている。Smith と Blinn は、異なる二つの背景の前で同じ前景を撮影し、背景が全画素で異なれば、前景の色とアルファを復元できることを示した（三角測量マッティング）。本稿の正解の復元は、背景を黒にした出力と、既知の背景を使った出力から、この考え方でアルファを求める（）。

色転写

Reinhard らは、一つの画像の色の平均と標準偏差を、別の画像のそれに合わせる色転写を提案した。計算は Ruderman らの lαβ 色空間で行い、チャンネルごとに独立に行う。この変換は画素ごとに働くため、前景と背景の絵柄が異なる合成画像でも、前景の色を背景の色に寄せられる。本稿では、この方法を自作の実装で用いて、色転写の強さを変えた合成を評価に使い、色転写が色の手がかりに与える影響を調べる。

手がかりの信頼度と分布の離れ

ラベルが一部の標本にしかない場合や、ラベルに誤りが含まれる場合の分類は、正例とラベルなしのデータからの学習や、ラベル雑音のもとでの学習として研究されている。Menon らは、二値ラベルが一定の割合で入れ替わる条件のもとで、誤ったラベルに対するAUCが、正しいラベルに対するAUCの一次関数になることを示した。この結果は、観測したクラスごとの分布を真の二つの分布の混合として表す、Scott らの定式化に基づく。Menon らは、この枠組みを mutually contaminated distributions と呼ぶ。本稿は、楕円の中心側と外側の画素を、誤りを含みうる前景と背景の標本とみなす。二つの分布の離れを測る量にバタチャリヤ係数があり、2クラスの分類のベイズ誤り率の上界を与える。本稿は、この係数で手がかりの信頼度を測る（）。

学習に基づく前景抽出

近年は、プロンプトを入力として任意の画像から領域を出力する大規模な学習済みモデルが示されている。このようなモデルは、学習データに由来する知識を使う点で、本稿の枠組みと前提が異なる。本稿は、学習を行わず、入力の画像と楕円だけから前景を推定する手法の性質を調べるものであり、学習済みモデルとの比較は行っていない。
